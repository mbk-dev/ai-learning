# Нативные субагенты Codex — веха 1

Комплект — учебная адаптация глобальных ролей автора. Нужен Codex с входом
через ChatGPT и поддержкой standalone TOML-ролей. API-ключи и другие провайдеры
не нужны. Доступность моделей и лимиты определяются аккаунтом ученика.

## Состав и установка

- `codex/native-subagents/agents/*.toml` → каталог `agents` в Codex home.
- `codex/native-subagents/config.fragment.toml` → объединить с глобальным config.
- Корневой `AGENTS.md` → учебные правила; объединить с глобальными инструкциями.

Codex home по умолчанию — `~/.codex` (Windows: `$HOME\.codex`).
Если задан `CODEX_HOME`, используй его. Windows и WSL — разные окружения:
устанавливай в то, где запускается Codex.

Перед изменением сделай отдельные резервные копии затрагиваемых файлов.
Существующие `config.toml` и `AGENTS.md` целиком не заменяй.
При наличии `AGENTS.override.md` проверь, какой файл реально загружается:
не считай изменение обычного AGENTS.md доказательством применения правил.
Не устанавливай комплект глобально автоматически: это влияет на все проекты;
установочный промпт ниже явно поручает именно глобальную установку.

Скопируй четыре TOML в каталог `agents`. При совпадении имени с существующей
ролью сравни содержимое. Идентичный файл оставь; отличающийся покажи ученику
до замены. Пользовательские роли с другими именами сохрани.

В config объедини ключи фрагмента с существующей таблицей `[agents]`.
Не создавай вторую одноимённую таблицу. В комплекте максимум три открытых
субагента; это учебный выбор, а не исходная настройка автора.
Если уже задан `max_threads`, учитывай его как прежнее имя лимита:
не оставляй два противоречащих значения.

В глобальные инструкции перенеси правила корневого AGENTS.md, объединив
повторы. Сохрани более строгие ограничения ученика; содержательный конфликт
сначала покажи ему. Ссылки на приватную инфраструктуру автора не нужны.
При установленном переопределяющем файле согласуй место правки с учеником.

## Роли и отличия от оригинала

| Роль | Модель | Reasoning |
| --- | --- | --- |
| explorer | gpt-6-luna | high |
| worker | gpt-6.1-terra | high |
| reviewer | gpt-6.1-sol | high |
| docs_researcher | gpt-6-luna | high |

Сохранены модели и основные инструкции автора. Удалены локальная ссылка
worker-pilot и настройки sandbox/MCP внутри файлов ролей: по текущей
документации они не переопределяют родительскую конфигурацию.
Браузерные роли и общий fallback в базовый комплект не входят.
Установщик не отключает у ученика его существующие MCP или плагины.
Формулировка «не редактировать» — инструкция роли, не гарантия изоляции.

Если модель недоступна, покажи доступные варианты и согласуй замену в TOML.
Не подключай API или стороннего провайдера ради сохранения имени модели.

## Промпт установки

Открой локальный checkout ai-learning в Codex и вставь
[готовый промпт](codex-native-subagents-setup-prompt.md).

## Проверка в новой сессии

После установки начни новую сессию Codex в отдельном учебном Git-проекте.
Сначала попроси проверить доступность четырёх ролей.
Затем выполни проверку с реальным запуском:

> Запусти explorer с явным типом роли. Поручи ему только прочитать README этого
> проекта, вернуть главный тезис и ссылку на строку. Не изменяйте файлы.
> Дождись ответа, проверь ссылку и заверши своего субагента.

Успех: Codex действительно создал explorer, получил ответ и проверил его.
Список файлов и слова «роли настроены» не доказывают запуск.
Проверку остальных ролей проведи на следующем упражнении с небольшой задачей:
исследование → worker → независимый reviewer; docs_researcher — при вопросе об API.
Не выдавай пробу explorer за проверку всех моделей и всех клиентов.

## Откат

Восстанови только изменённые файлы из резервных копий, сверив последующие
ручные правки. Удали только добавленные этим комплектом роли и ключи.
Начни новую сессию. Не удаляй весь каталог Codex home.
